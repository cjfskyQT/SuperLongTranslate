# 超长文本翻译

把任意长度的文本整篇翻译，**不受网页版 5000 字符限制**。只做纯文本翻译，不含图片 / 文档 / 网页翻译。

---

## 一、为什么 5000 字符是可以绕过的

动手前先做了实测，结论直接决定架构：

| 引擎 | 实测结论 |
|---|---|
| **Google** | 5000 字符是**网页输入框的限制，后端并没有真的卡**。改用 `POST` 后，单次提交远比 5000 字符长得多的文本，仍然完整返回、不截断。 |
| **Google（GET）** | 走 GET 会被直接 **429 限流**，必须用 POST。 |
| **百度** | 新版网页改为 SPA，`window.gtk` token 机制已下线，`/basetrans` 无 token 时返回空包——**网页内部接口已不可用**。因此对接[百度开放平台官方 API](https://fanyi-api.baidu.com/)，单次上限 6000 **字节**（中文 3 字节/字，约 2000 字）。 |

这里得说一句 Google：网页上给你框一个 5000，看起来像个硬性上限，但后端其实放得开得多得多，并没有在服务端偷偷卡你，也没有静默截断——**这种不设防的厚道，挺让人省心的**。所以本工具的做法就是：**按自然段切分 → 并发逐片翻译 → 按原序拼接，段落结构原样保留**。

---

## 二、快速开始

```bat
双击 run.bat
```

首次运行会自动装依赖，浏览器打开 <http://127.0.0.1:8765/>。之后每次双击即可。
（端口被占用时自动改用 8766）

把文本粘贴进左框，或直接把 `.txt` / `.md` 文件**拖进去**，选好目标语言，点「开始翻译」。

### 命令行批处理

```bat
python cli.py book.txt -t "中文（简体）"
python cli.py book.txt -e google -s "英语" -t "日语" -o 日文版.txt
python cli.py big.md -e baidu -c 3
```

| 参数 | 说明 |
|---|---|
| `-e` | `google`（默认，免费）或 `baidu`（需密钥） |
| `-s` / `-t` | 源语言 / 目标语言，如 `"英语"`、`"日语"`；源语言默认自动检测 |
| `-o` | 输出路径，默认 `<原名>_translated.txt`（UTF-8 带 BOM，Windows 记事本直接打开不乱码） |
| `-c` | 并发数，默认 4 |
| `-r` | 单片最大重试次数，默认 4 |
| `-l` | 每片上限，`0` = 引擎默认值 |
| `--allow-degradation` | 存在整段超长时，允许工具在段内自动切分（默认停下来提示你先分段） |

## 三、切分策略：段落优先

**默认只以段落为切分单位，不为了凑长度把段落或句子切碎。**

1. 先按空行 / 换行切出自然段；
2. 按段落装箱，整段进同一片，只在段落之间断开；
3. **只有当单个段落本身**超过单次上限时，才需要段内切分。

### 超长段落会停下来问你

如果第 3 步会真的发生（某一段整段就超限），工具**不会默默切碎**，而是先停下来：

- **界面上**：点「开始翻译」后先做本地预检（不消耗任何翻译额度），
  发现超长段落就弹出对话框，列出「第几段、多少字符、上限是多少、内容开头」，
  并建议你在该段的自然停顿处空一行分成小段。你可以选「我去分段」或「忽略，仍自动切分」。
- **命令行**：默认**拒绝翻译**并退出（exit code 5），列出所有超长段落并提示：

  ```
  [x] 有 1 个段落整段超过单次上限，按段落切不开：
      第 2 段  8,992 字符（上限 4,365 字符）
      ...
      建议：在这些段落的自然停顿处空一行（或换行）分成小段，译文会更自然。
      确认要让工具在段内自动切分，则加参数：
          python cli.py over.txt -e google --allow-degradation
  ```

只有你明确确认后，才会启用降级：段内在**句末标点**处切开，其余段落依然整段下发。
后端也会强制校验——未确认时 `/api/translate` 与 `/api/translate/stream` 都返回 **409**，
不会因为某个客户端漏传参数就悄悄降级。

切分器守护两条可测试的不变量：

- **零丢失**：`"".join(chunk.text + chunk.joiner) == original_text`（含 CRLF 原样保留）
- **连续子串**：每个片段都是原文的一段连续子串（只切不插值）

两者均由 `tests/test_chunker.py` 的属性测试覆盖（13 组边界样本：空文本、纯空白、CRLF、无标点超长串、版本号小数、引号收尾等）。

### 百度为什么按字节切

百度官方 API 限制的是 `q` 的 **UTF-8 字节数**（6000 字节）。一个汉字 3 字节，所以 5800 字节实际只够约 1900 个汉字。引擎声明 `measure_is_bytes = True`，切分器自动切换为字节计量——中文不会被切超。

## 四、稳定性设计

| 机制 | 作用 |
|---|---|
| 并发信号量 | 免费端点对并发敏感，默认 4，防止被打挂 |
| 指数退避 + 抖动 | 429 / 5xx 自动重试，避免重试风暴 |
| **失败自动二分** | 某片因长度失败时一分为二递归重试，而不是让整篇失败 |
| 片段去重 | 长文里重复段落只翻一次 |
| 失败不阻断 | 失败片保留原文占位，其余照常产出，最后汇总上报 |
| 连接池复用 | `httpx.AsyncClient` 共享连接，是长文吞吐的关键 |
| SSE 进度 | 实时进度、速度、ETA，可随时取消 |

实测：200 段 / 36,890 字符 → 切 9 片、**0 降级**、5.8 秒完成、段数守恒。

---

### 目标语言选成「自动检测」时

译到"自动检测"是没有意义的，所以工具会**按原文实际语种自动兜底**：

| 原文语种 | 自动设为 |
|---|---|
| 中文 | 英语 |
| 日语 / 韩语 / 拉丁字母（英德法等） | 中文（简体） |

界面上会在译文栏下方显示「原文为中文 → 目标自动设为英语」的小提示，
下拉框也会同步成实际使用的语言。**你手动选了目标语言就完全不受影响。**

语种识别是本地 Unicode 区段统计（`app/langdetect.py`），不联网、不卡顿：
假名 / 谚文是决定性特征，所以日语里的汉字不会被误判成中文；
拉丁字母不细分语种——反正译成中文都合适。

## 五、百度引擎配置

1. 打开 <https://fanyi-api.baidu.com/> 注册，领取 **App ID** 和 **Secret**
2. 界面上选「百度翻译（官方 API，需密钥）」，填入并保存

凭据明文保存在本机 `data/settings.json`，不会外传；界面回显时自动打码。也可用环境变量 `BAIDU_APPID` / `BAIDU_SECRET` 覆盖。

> 注意：百度免费版有每月字符额度限制（标准版 1 万字符/月）。长文建议用 Google 引擎，或用完及时清理配额。

## 六、目录结构

```
SuperLongTranslate/
├─ run.bat                    一键启动
├─ cli.py                     命令行批处理
├─ requirements.txt
├─ app/
│  ├─ chunker.py              ★ 段落优先切分器 + 不变量
│  ├─ pipeline.py             ★ 并发 / 退避重试 / 自动二分 / 去重
│  ├─ config.py               配置持久化（凭据脱敏）
│  ├─ main.py                 FastAPI 服务端 + 预检 / SSE / TTS 代理
│  └─ engines/
│     ├─ base.py              引擎抽象 + 统一语言表（各引擎自动取对应语言码）
│     ├─ google.py            免费端点，POST
│     └─ baidu.py             官方开放平台 API，按字节计量
├─ web/                       前端（原生 HTML/CSS/JS，无构建步骤）
├─ tests/test_chunker.py      切分器属性测试
├─ e2e_check.py               端到端验证（真实调用引擎）
├─ http_check.py              HTTP 层验证
└─ frontend_contract_check.mjs 前端 DOM id 契约校验
```

## 八、已知限制

- **Google 免费端点非官方**，随时可能变更；已做好失败退避与明确报错，建议并发别调太高
- 界面上的「朗读」用 Google TTS，仅前 4000 字，可能被限流
- 不支持图片 / PDF / Word / 网页翻译（按需求范围）
- 单次输入上限 2000 万字符（防御性限制）
